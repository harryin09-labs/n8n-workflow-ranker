# Contributing to n8n Workflow Intelligence & Ranking System

We love community contributions! Whether you're fixing a bug, adding a new scoring dimension, or improving the dashboard, your help makes this system smarter and more reliable.

## 🚀 How to Contribute

1. **Fork the Repo**: Create your own fork of `harryin09-labs/n8n-workflow-ranker`.
2. **Create a Branch**: `git checkout -b feature/your-feature-name`
3. **Make Changes**: Follow the project structure defined in the [README](README.md).
4. **Test**: Run `python -m pytest -v` to ensure everything is working correctly.
5. **Commit & Push**:
   ```bash
   git commit -m "feat: description of your changes"
   git push origin feature/your-feature-name
   ```
6. **Open a PR**: Submit a pull request with a clear description of what your changes achieve.

## 💡 What We Need Help With
- **New Scoring Dimensions**: Do you have ideas for better workflow evaluation?
- **Dashboard Improvements**: Enhancing the Streamlit UI.
- **Bug Fixes**: Improving crawling robustness.
- **Documentation**: Making it easier for newcomers to get started.
